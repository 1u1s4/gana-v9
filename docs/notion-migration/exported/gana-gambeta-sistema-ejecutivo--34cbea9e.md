# Gana/Gambeta - Sistema ejecutivo

Created on 2026-04-23. Notion is the durable executive system of record for goals, hiring, risks, and updates. Paperclip remains the execution and delegation system.
## Executive governance
- Notion: durable executive state, decisions, hiring, risks, and periodic updates.
- Paperclip: execution ownership, delegation, issue state, and heartbeat commentary.
- Repo docs: detailed technical plans, hiring packets, and implementation artifacts.
## Operating cadence
- CEO: weekly update on goal health, wedge choice, and blocker decisions.
- CTO: daily update on roadmap movement, hiring progress, technical blockers, and executive risks.
- Founding Engineer: daily or per-shipment update on owned delivery lanes, blockers, and next merge-ready slice.
- Webscraper: daily during sourcing/trial, then per collection run once hired; must log evidence, drift, blockers, and next safe slice.
- CMO: three times per week on growth/content experiments, channel learning, and free-to-paid conversion signals.
