# Editorial, SEO y GTM

## Decision

SEO y contenido son parte del producto de confianza, no un blog separado. Cada pieza debe reforzar:

- criterio de picks;
- transparencia de resultados;
- educacion de riesgo;
- retorno al feed publico;
- conversion hacia alertas, DM o Private Board.

## Clusters editoriales

| Cluster | Proposito | CTA natural |
| --- | --- | --- |
| AI picks education | Explicar como funcionan y sus limites | Ver picks gratis |
| Bankroll | Unit staking, limites, evitar chase betting | Guardar board/recibir alertas |
| Value betting | Probabilidad vs cuota, EV basico | DM `TRIAL` para board completo |
| Leagues | Liga MX, Premier League, LaLiga, Champions, Mundial | Seguir liga / alertas |
| Market explainers | 1X2, BTTS, totals, Asian handicap, corners | Ver ejemplo en pick card |
| Results methodology | Como se califican wins/losses/voids | Ver historial publico |
| Responsible gambling | +18, limites, no garantias | Volver al feed con contexto |
| Luis weekly review | Recap de aciertos, errores y aprendizajes | Entrar a Private Board |

## Reuse social

Cada pick o articulo debe poder transformarse en:

- card X con pick, tier, cuota, riesgo y URL canonica;
- thread corto con 2-3 aprendizajes;
- TikTok/Reel de un insight;
- alerta Telegram/WhatsApp;
- recap semanal;
- FAQ/SEO snippet.

## GTM inicial

Secuencia recomendada:

1. Public picks feed con responsible-gambling copy visible.
2. Results/history append-only para confianza.
3. Alert opt-in y DM keyword tracking.
4. Private Board barato cuando existan recibos publicos.
5. SEO/FAQ y league pages para demanda organica.
6. Personal panel solo despues de validar feed + ledger + alertas.

## Mensaje comercial

Gana v9 no debe posicionarse como "picks seguros". El mensaje correcto:

- picks de futbol revisados por Luis;
- rationale corto;
- riesgo visible;
- resultados transparentes;
- acceso paid para velocidad, orden y contexto adicional.

## Linea editorial prohibida

- Clonar lenguaje, UI, assets o mechanics de competidores.
- Vender ranking, coins o VIP como si fueran prueba de certeza.
- Publicar ROI antes de reglas y sample size.
- Convertir contenido educativo en advice financiero/personalizado.
