## Principios

- La capa gratis debe entregar valor antes de pedir registro o pago.
- La CTA por pieza debe ser una sola. Default operativo: `DM "TRIAL"` hasta que CEO/board apruebe un destino mejor.
- No se publican picks sin feed fresco, tesis, riesgo principal y owner claro.
- No se presentan anchors viejos como advice vivo de una fecha nueva.
- Toda pieza publica debe incluir lenguaje de riesgo: `18+ only. No guaranteed profit. Bet responsibly.`
- Las metricas reales requieren URLs/post IDs reales; no se inventan views, clicks, DMs, opt-ins ni conversion conocida.
