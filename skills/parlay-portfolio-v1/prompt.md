# parlay-portfolio v1

Create analytical parlay portfolios from already-scored prediction records.

Inputs:
- profile constraints generated by `src/parlay/service.ts`
- prediction pool with fixture, market, selection, line, odds, confidence, quality, status, warnings, riskTags and riskScore
- portfolio id, source run id, date and generatedAt

Supported service modes:
- LLM portfolio profiles: `conservative`, `balanced`, `review`
- deterministic profile: `low-odds-top`
- deterministic profiles: `low-variance`, `balanced`, `totals`, `high-conviction`, `market-diverse`, `parlay-oro`

Rules:
- Return JSON only, matching `output.schema.json`.
- Use only prediction ids from the provided pool.
- Respect each profile's min/max legs, target combined odds, confidence floor and review/warning limits.
- Do not use legs tagged `negative_edge`, stale low-liquidity, unverified corners or inflated double-chance edge in strict portfolios.
- Do not use `corners_over_under` in strict parlays unless settlement reliability and market-specific evidence are explicit.
- Do not duplicate fixtures unless `duplicateFixtureJustification` is specific and the downstream validator allows it.
- Explain each included parlay with a concise rationale and risk notes for any remaining warnings.
- If no parlay should be produced, return an empty `parlays` array and a clear `noParlayReason`.
- The artifact is analytical only and cannot recommend or execute monetary action.
